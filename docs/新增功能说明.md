# 新增功能说明：差分金额脱敏模式

## 功能概述

在原有金额脱敏模式（降低精度、随机扰动、遮掩）的基础上，新增了两种差分脱敏模式：

1. **差分偏移模式 (differential_shift)**：所有金额加上相同的固定偏移量，保持金额之间的差值不变
2. **比例缩放模式 (proportional_scale)**：所有金额乘以相同的比例因子，保持金额之间的比例关系不变

## 使用示例

### 示例 1：资产负债表差分偏移

```yaml
sites:
  - site_id: sheet_资产负债表_B2
    original_value: "10000000"
    action: differential_shift
    params:
      shift: "1139426.80"
  
  - site_id: sheet_资产负债表_B10
    original_value: "6000000"
    action: differential_shift
    params:
      shift: "1139426.80"  # 必须与资产使用相同的偏移量
  
  - site_id: sheet_资产负债表_B15
    original_value: "4000000"
    action: differential_shift
    params:
      shift: "1139426.80"  # 必须与资产和负债使用相同的偏移量
```

### 示例 2：利润表比例缩放

```yaml
sites:
  - site_id: sheet_利润表_B2
    original_value: "10000000"
    action: proportional_scale
    params:
      scale: "1.0418"
  
  - site_id: sheet_利润表_B3
    original_value: "7000000"
    action: proportional_scale
    params:
      scale: "1.0418"  # 必须与营业收入使用相同的缩放因子
  
  - site_id: sheet_利润表_B4
    original_value: "3000000"
    action: proportional_scale
    params:
      scale: "1.0418"  # 必须与营业收入和成本使用相同的缩放因子
```

### 示例 3：使用预计算功能

```python
from finance_mask.engine.amount import AmountRedactor

# 差分偏移
values = ["10000000", "6000000", "4000000"]
results, shift = AmountRedactor.generate_differential_sequence(values)
print(f"建议偏移量: {shift}")

# 比例缩放
results, scale = AmountRedactor.generate_proportional_differential_sequence(
    values, percentage=10.0
)
print(f"建议缩放因子: {scale}")
```

## 适用场景

### 差分偏移模式适用场景

1. **资产负债表**：资产 = 负债 + 所有者权益，差值关系重要
2. **收入支出对比**：需要保持收支差额
3. **多期对比数据**：需要保持增长/下降趋势
4. **预算执行分析**：需要保持预算与实际的差额

### 比例缩放模式适用场景

1. **利润表**：需要保持毛利率、净利率等比率指标
2. **收入结构分析**：需要保持各项收入占比
3. **成本结构分析**：需要保持各项成本占比
4. **财务比率分析**：需要保持各种财务比率

## 注意事项

1. **一致性要求**：需要保持关系的多个金额必须使用相同的偏移量/缩放因子
2. **参数选择**：偏移量/缩放因子应根据业务场景合理设置
3. **审计日志**：差分模式会在日志中记录使用的偏移量/缩放因子
4. **水印嵌入**：差分模式不影响水印的嵌入和解码
