# 差分脱敏模式说明

## 概述

差分脱敏是一种特殊的金额脱敏方式，它通过给所有金额添加相同的偏移量或缩放因子，保持金额之间的差值或比例关系不变。

## 两种差分模式

### 1. 差分偏移模式 (differential_shift)

**原理**：所有金额加上相同的固定偏移量

**数学表示**：
- 原始值：A, B, C
- 偏移量：Δ
- 脱敏后：A+Δ, B+Δ, C+Δ

**保持的关系**：
- 差值不变：(B+Δ) - (A+Δ) = B - A
- 总量变化：新总量 = 原总量 + N×Δ（N为金额数量）

**适用场景**：
- 资产负债表（资产 = 负债 + 所有者权益）
- 收入支出对比（需要保持收支差额）
- 多期对比数据（需要保持增长/下降趋势）
- 需要保持绝对差值的场景

**示例**：
```
原始数据：
  资产：10,000,000 元
  负债：6,000,000 元
  所有者权益：4,000,000 元
  
偏移量：+1,000,000 元

脱敏后：
  资产：11,000,000 元
  负债：7,000,000 元
  所有者权益：5,000,000 元
  
验证：资产 - 负债 = 所有者权益
  原始：10,000,000 - 6,000,000 = 4,000,000 ✓
  脱敏：11,000,000 - 7,000,000 = 5,000,000 ✓
```

### 2. 比例缩放模式 (proportional_scale)

**原理**：所有金额乘以相同的比例因子

**数学表示**：
- 原始值：A, B, C
- 缩放因子：k
- 脱敏后：k×A, k×B, k×C

**保持的关系**：
- 比例不变：(k×B) / (k×A) = B / A
- 差值比例不变：(k×B - k×A) / (k×A) = (B - A) / A

**适用场景**：
- 利润表（需要保持毛利率、净利率等比率指标）
- 收入结构分析（需要保持各项收入占比）
- 需要保持相对关系的场景

**示例**：
```
原始数据：
  营业收入：10,000,000 元
  营业成本：7,000,000 元
  毛利润：3,000,000 元
  
原始毛利率：30%

缩放因子：1.1

脱敏后：
  营业收入：11,000,000 元
  营业成本：7,700,000 元
  毛利润：3,300,000 元
  
验证毛利率：
  原始：3,000,000 / 10,000,000 = 30% ✓
  脱敏：3,300,000 / 11,000,000 = 30% ✓
```

## 使用方法

### 1. 在策略文件中配置

```yaml
sites:
  - site_id: sheet_资产负债表_B2
    location:
      type: excel
      sheet: 资产负债表
      cell: B2
    original_value: "10000000"
    detected_type: amount
    enabled: true
    action: differential_shift  # 或 proportional_scale
    params:
      shift: "1000000"  # 差分偏移模式
      # 或
      scale: "1.1"      # 比例缩放模式
```

### 2. 使用预计算功能

```python
from finance_mask.engine.amount import AmountRedactor

# 差分偏移
values = ["10000000", "6000000", "4000000"]
results, shift = AmountRedactor.generate_differential_sequence(values)
print(f"建议偏移量: {shift}")

# 比例缩放
results, scale = AmountRedactor.generate_proportional_differential_sequence(
    values, percentage=10.0
)
print(f"建议缩放因子: {scale}")
```

### 3. 批量处理时保持一致性

对于需要保持关系的多个金额，必须使用相同的偏移量或缩放因子：

```yaml
# 正确示例：所有金额使用相同的偏移量
sites:
  - site_id: 资产
    action: differential_shift
    params:
      shift: "1000000"
  
  - site_id: 负债
    action: differential_shift
    params:
      shift: "1000000"  # 必须与资产相同
  
  - site_id: 所有者权益
    action: differential_shift
    params:
      shift: "1000000"  # 必须与资产和负债相同
```

## 与其他模式的对比

| 特性 | 随机扰动 (perturb) | 差分偏移 (differential_shift) | 比例缩放 (proportional_scale) |
|------|-------------------|------------------------------|------------------------------|
| 保持总量 | ✓ | ✗ | ✗ |
| 保持差值 | ✗ | ✓ | ✗ |
| 保持比例 | ✗ | ✗ | ✓ |
| 适用场景 | 需要保持总量的汇总数据 | 需要保持差值的对比数据 | 需要保持比例的结构数据 |
| 典型应用 | 合并报表、汇总统计 | 资产负债表、收支对比 | 利润表、收入结构 |

## 注意事项

1. **一致性要求**：需要保持关系的多个金额必须使用相同的偏移量/缩放因子
2. **参数选择**：偏移量/缩放因子应根据业务场景合理设置，避免脱敏后数据明显不合理
3. **审计日志**：差分模式会在日志中记录使用的偏移量/缩放因子，便于追溯
4. **水印嵌入**：差分模式不影响水印的嵌入和解码
