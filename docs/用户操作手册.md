# 财务文件智能脱敏工具 - 用户操作手册

## 一、简介

财务文件智能脱敏工具是一款纯本地运行的 Python CLI 工具，用于自动扫描、脱敏和水印嵌入财务文件（.xlsx 和 .pptx 格式）。

### 主要功能

- **智能发现**：自动扫描文件中的敏感内容（金额、机构名、人名、账号等）
- **策略可审**：生成可人工审核和编辑的 YAML 策略文件
- **一键执行**：按策略自动执行脱敏，保留原格式
- **可溯源**：在脱敏文件中嵌入隐形水印，实现分发文件溯源

## 三、命令详解

### 3.1 生成策略（generate）

扫描文件并生成 YAML 策略文件。

```bash
python -m finance_mask generate -i <输入> -o <策略文件>
```

**参数说明：**

| 参数 | 简写 | 必填 | 说明 |
|------|------|------|------|
| --input | -i | 是 | 输入文件或文件夹路径 |
| --output | -o | 是 | 输出的策略文件路径（.yaml） |
| --verbose | -v | 否 | 显示详细日志 |

**示例：**

```bash
# 扫描单个文件
python -m finance_mask generate -i 2024年度财务报告.pptx -o 策略.yaml

# 扫描文件夹
python -m finance_mask generate -i ./待处理/ -o 策略.yaml
```

### 3.2 执行脱敏（redact）

按策略文件执行脱敏。

```bash
python -m finance_mask redact -i <输入> -s <策略文件> -o <输出目录>
```

**参数说明：**

| 参数 | 简写 | 必填 | 说明 |
|------|------|------|------|
| --input | -i | 是 | 输入文件或文件夹路径 |
| --strategy | -s | 条件 | 策略文件路径（与 --default-policy 二选一） |
| --default-policy | - | 条件 | 使用内置默认策略（与 -s 二选一） |
| --output | -o | 是 | 输出目录 |
| --operator | - | 否 | 操作人ID（默认取系统用户名） |
| --verbose | -v | 否 | 显示详细日志 |
| --force | -f | 否 | 覆盖已存在的输出文件 |
| --dry-run | - | 否 | 仅预览拟修改位点，不实际执行 |

**示例：**

```bash
# 使用策略文件脱敏
python -m finance_mask redact -i 2024年度财务报告.pptx -s 策略.yaml -o ./输出/ --operator finance_zhang

# 使用默认策略快速脱敏
python -m finance_mask redact -i ./待处理/ --default-policy -o ./脱敏输出/

# 预览模式（不实际修改文件）
python -m finance_mask redact -i 2024年度财务报告.pptx -s 策略.yaml -o ./输出/ --dry-run
```

### 3.3 水印解码（decode-watermark）

从脱敏文件中提取和验证水印。

```bash
python -m finance_mask.decode_watermark <文件路径>
```

**示例：**

```bash
python -m finance_mask.decode_watermark 2024年度财务报告_脱敏.pptx
```

## 五、策略文件说明

策略文件是 YAML 格式，包含所有敏感位点的脱敏配置。

### 策略文件结构

```yaml
metadata:
  version: "1.0"
  source_file: 2024年度财务报告.pptx
  generated_at: "2024-01-01T10:30:00"
  total_sites: 47

column_rules:
  - match_type: exact
    pattern: 营业收入
    action: precision
    params:
      unit: million
      decimal_places: 2
    detected_type: amount

sites:
  - site_id: slide_3_textbox_5
    location:
      type: ppt
      slide: 3
      shape_id: 营收数据
    original_value: "1,234,567,890.12"
    detected_type: amount
    discovered_by: column_rule
    enabled: true
    action: precision
    params:
      unit: million
      decimal_places: 2
```

### 常用配置

**跳过某个位点：**
```yaml
enabled: false  # 设为 false 可跳过此位点
```

**修改脱敏方式：**
```yaml
action: perturb  # 可选: precision / perturb / mask / alias / mask_name / mask_account
params:
  percentage: 5  # 扰动百分比
```

## 六、脱敏模式说明

### 6.1 金额脱敏

| 模式 | 说明 | 参数 | 示例 |
|------|------|------|------|
| precision | 降低精度 | unit, decimal_places | 12,345,678.90 → 12.35百万元 |
| perturb | 随机扰动 | percentage | 12,345,678.90 → 12,234,567.89（±5%） |
| mask | 遮掩 | 无 | 12,345,678.90 → 1*,***,***.** |
| differential_shift | 差分偏移 | shift | 12,345,678.90 → 12,445,678.90（+10万） |
| proportional_scale | 比例缩放 | scale | 12,345,678.90 → 13,580,246.79（×1.1） |

### 6.2 名称脱敏

| 模式 | 说明 | 参数 | 示例 |
|------|------|------|------|
| alias | 代号替换 | prefix | 阿里巴巴集团 → [公司A] |
| mask_name | 姓名遮掩 | keep_first | 张三 → 张* |

### 6.3 账号脱敏

| 模式 | 说明 | 参数 | 示例 |
|------|------|------|------|
| mask_account | 账号遮掩 | keep_prefix, keep_suffix | 6222021234567890123 → 622***********0123 |

## 七、常见问题

### Q1: 为什么某些敏感内容没有被发现？

A: 工具使用双重扫描引擎：
1. **列头定位**：根据表头自动识别列内容类型
2. **全文正则**：使用正则表达式匹配敏感内容

如果内容不在表头定义的列中，且不匹配内置正则规则，可能会被遗漏。建议：
- 检查策略文件，手动添加遗漏的位点
- 联系开发团队添加自定义规则

### Q2: 脱敏后公式丢失了怎么办？

A: 当前版本在替换单元格值时，公式会被转换为值。如果需要保留公式，请：
- 在策略文件中将该位点的 `enabled` 设为 `false`
- 手动处理公式单元格

### Q3: 如何添加自定义规则？

A: 目前版本支持在策略文件中手动添加位点。未来版本将支持外部规则配置文件。

### Q4: 水印会被删除吗？

A: 工具使用多点冗余嵌入策略，水印分散嵌入文件多个位置。删除 50% 的嵌入点后，剩余水印仍可重组解码（检出率 ≥ 80%）。

### Q5: 批量处理时某个文件失败会影响其他文件吗？

A: 不会。单个文件处理失败不影响其他文件，最后会输出汇总报告。

### Q6: 差分偏移和比例缩放模式有什么区别？

A: 
- **差分偏移 (differential_shift)**: 所有金额加上相同的固定值，保持金额之间的**差值**不变。适用于需要保持收支差额、资产负债平衡等场景。
- **比例缩放 (proportional_scale)**: 所有金额乘以相同的比例因子，保持金额之间的**比例**不变。适用于需要保持增长率、毛利率等比率指标的场景。

### Q7: 如何为差分模式生成统一的偏移量或缩放因子？

A: 在策略文件中，需要为使用差分模式的所有位点指定相同的 `shift` 或 `scale` 参数。可以手动设置，也可以使用工具预计算：

```python
from finance_mask.engine import AmountRedactor

values = ["1000000", "2000000", "3000000"]
# 差分偏移
results, shift = AmountRedactor.generate_differential_sequence(values)
print(f"偏移量: {shift}")

# 比例缩放
results, scale = AmountRedactor.generate_proportional_differential_sequence(values, percentage=10.0)
print(f"缩放因子: {scale}")
```

## 八、错误码说明

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| E001 | 输入文件不存在 | 检查文件路径是否正确 |
| E002 | 不支持的文件格式 | 仅支持 .pptx 和 .xlsx 格式 |
| E003 | 策略文件格式错误 | 检查 YAML 语法是否正确 |
| E004 | 输出目录无写入权限 | 检查目录权限 |
| E005 | 文件被其他程序占用 | 关闭占用文件的程序后重试 |
| E006 | 策略中必填字段缺失 | 检查策略文件完整性 |
| E007 | 位点定位失败 | 文件可能已被修改，重新生成策略 |
